# Praktikum Error Handling PHP — Pertemuan 18

Repositori ini berisi hasil praktik dan studi kasus penanganan error (*Error Handling*) pada bahasa pemrograman PHP berdasarkan materi **Pemrograman Web II (Pertemuan 18)**. Setiap studi kasus dibagi menjadi dua bagian: simulasi kode yang memicu error (`error/`) dan kode perbaikan yang sudah sesuai aturan (`solusi/`).
